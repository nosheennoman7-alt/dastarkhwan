# Biryani Bot

A restaurant web app with an AI assistant for **Ali's Biryani House, Manchester**.

> Status: project structure only. No website or application logic has been written yet.

## Project structure

```
dastarkhwan/
├── frontend/        Website the customer sees
│   ├── index.html   Page markup
│   ├── styles.css   Styling
│   └── app.js       Browser-side script
├── backend/         Server code (e.g. the API the AI assistant talks to)
├── data/            Restaurant data (menu, opening hours, location, etc.)
├── prompts/         Instructions and prompt text for the AI assistant
├── .gitignore
└── README.md
```
